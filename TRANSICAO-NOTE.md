# Transição Intro → Home — v1

A intro aprovada foi mantida. Esta versão adiciona somente a ponte visual entre a intro e a Home:
- o site entra suavemente por baixo do overlay;
- o canvas mantém um pulso central e linhas radiais sutis por ~1,45s;
- o overlay fica translúcido durante o handoff;
- depois a intro é removida.

A transição é propositalmente discreta para preservar a identidade premium.
